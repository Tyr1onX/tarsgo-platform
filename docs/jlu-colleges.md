# 吉林大学本科生学院字典

学院选项使用稳定英文 code 和官方中文名称。名单按本科专业归属整理，并用当前院系名称更新曾用名；文学院与其新闻传播本科归属合并显示。列表覆盖 45 个本科招生学院，不包含工程训练中心、公共计算机教学与研究中心等教学或研究中心，也不包含附属单位。

核对日期：2026-10-06。

来源均为吉林大学官方页面：

- [本科专业设置与所属学院（2025 年表，吉林大学本科生院，2025-10-20 发布；统计页于 2026-01-12 更新）](https://gongkai.jlu.edu.cn/info/1058/9391.htm)
- [本科专业总表（吉林大学本科生院，2026-01-12 更新）](https://www.jlu.edu.cn/info/1078/1772.htm)
- [现行院系设置](https://www.jlu.edu.cn/jgsz/yxsz.htm)
- [2026 级本科新生学院安排（吉林大学校医院，2026-09-02 发布）](https://xyy.jlu.edu.cn/info/1143/6085.htm)
- [2026 年本科招生学院总数（吉林大学新闻中心，2026-07-02 发布）](https://news.jlu.edu.cn/info/1211/61544.htm)

2026 本科生院总表列出当前专业，但不逐项列学院；因此以官方本科专业所属学院表为基础，按现行院系名称校正，并用 2026 级本科新生安排与学校公布的 45 个本科招生学院交叉核对。历史成员的学院保持为空，字典变更也不会自动改写已保存的成员资料。
